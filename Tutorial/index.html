Preface

This is a text-based guide on how to create and implement HD assets, such as characters and backgrounds, into AAO games. If you are learning this for the first time, I recommend you play this interactive tutorial on AAO first; it contains more images for visual reference, is self-demonstrating (because it's an AAO tutorial on... AAO), and is (hopefully) more entertaining to use and learn through.

However, if you are unable to play the AAO case for whatever reason or just want to quickly reference a piece of information in a (somewhat) more formal tone, then this is a suitable alternative; the info featured between these 2 guides should be the same, barring any oversights.
